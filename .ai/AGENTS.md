# AGENTS.md

## What is this about?

This project is an HTTP server written in C. It is built from scratch (sockets, request parser, HTTP protocol) in order to learn how HTTP and network programming work. Details can be found in `docs/`.

## Rules for AI Agents

1. **Do not touch files.** Files may only be created, modified, moved or deleted with the explicit permission of the user.
2. **Only answer questions.** The AI explains, answers questions and gives hints. It does not write code or files unless the user explicitly says otherwise.
3. **Do not write the final code in your response.** Even in a chat reply, do not provide the finished, ready-to-use solution. Guide with explanations, hints and small illustrative snippets at most, so the user writes the final code themselves.
4. **When in doubt, ask.** If it is unclear whether something is allowed, do not do it, but ask first.
